# 前缀缓存 · 用一个例子讲透（v2 · 已修正注意力部分）

> **v2 改了什么**：v1 为了好懂，把注意力写成了"求平均"——**那是错的简化**。
> v2 换成**真公式 + 真计算**。
>
> **读法**：先只看【第一部分：例子】，把数走通；再看【第二部分：点名】。
> **想逐句问**，报编号（如 `1.5.3`）。

# 第一部分：例子

## 1.1 设定一个"玩具模型"

**1.1.1** 只有 **2 层**。（为什么必须是 2 层，`1.7` 会讲。）

**1.1.2** 每个 token 变成一个 **2 维向量**。（真实是几百上千维，这里用 2 个数代表，**道理一样**。）

**1.1.3** 词表里就几个 token，先把向量定好：

```
A = [1, 0]
B = [0, 1]
C = [1, 1]
D = [2, 0]
X = [3, 0]     ← "捣乱"用的 token，1.5 出场
```

## 1.2 真正的注意力公式（三步）

**1.2.1** 只看**一个位置 i**（它要"回头看前面"）：

```
① 打分：   s_ij = (q_i · k_j) / √d      ← 点积，再缩放
② 归一化： α_ij = softmax(s_ij)          ← 对 j（所有前面位置）做 softmax
③ 汇总：   output_i = Σ_j α_ij · v_j     ← 按权重把 v 加权求和
```

**1.2.2** 矩阵形式（你可能见过的那个）：

```
Attention = softmax( Q Kᵀ / √d ) · V
```

**1.2.3** **因果遮罩（causal mask）**：位置 i 只能看 **j ≤ i**。
所以例子里，D 只看 `A B C D`，**看不到后面的 `1 2 3`**。

**1.2.4** 注意：**"注意力就是求平均"只在"所有分数都相等"时才成立**——那是个退化特例。真实是"**谁跟我像，我就多听谁的**"。

## 1.3 算一遍：请求 1 = `A B C D 1 2 3`

**1.3.1** 简化：假装三个投影矩阵都是单位阵，于是 **Q = K = V = token 自己那个向量**。
（真实要乘 W_Q/W_K/W_V，省掉不影响看机制。）

**1.3.2** 缩放系数：`√d = √2 ≈ 1.414`。

**1.3.3** 每个位置的结果（只算到 D）：

```
位置 A：只有它自己
   s = [1,0]·[1,0]/1.414 = 0.707   → softmax 后 α=1.00
   h1_A = [1, 0]

位置 B：看 A、B
   q_B=[0,1]  A→0  B→0.707
   exp: 1.000, 2.028   和=3.028   α: 0.330, 0.670
   h1_B = 0.330·[1,0] + 0.670·[0,1] = [0.33, 0.67]

位置 C：看 A、B、C
   q_C=[1,1]  A→0.707  B→0.707  C→1.414
   exp: 2.028, 2.028, 4.113   和=8.169   α: 0.248, 0.248, 0.504
   h1_C = 0.248·[1,0] + 0.248·[0,1] + 0.504·[1,1] = [0.75, 0.75]

位置 D：看 A、B、C、D          ★ 记住这个
   q_D=[2,0]  A→1.414  B→0  C→1.414  D→2.828
   exp: 4.113, 1.000, 4.113, 16.912   和=26.139   α: 0.157, 0.038, 0.157, 0.647
   h1_D = 0.157·[1,0] + 0.038·[0,1] + 0.157·[1,1] + 0.647·[2,0]
        = [1.61, 0.20]
```

**1.3.4** 注意 D 这里：**D 自己拿走了 0.647 的权重**——因为 D 最像自己。**这不是平均**（平均的话每个都是 0.25）。

**1.3.5** 然后 **第 2 层**：输入就是第 1 层的输出。第 2 层给 D 位置算出的 K、V：

```
K2_D = [1.61, 0.20]
V2_D = [1.61, 0.20]
```

**1.3.6** **这两个数，就是"缓存里存的东西"**（第 2 层、D 位置）。

## 1.4 请求 2 = `A B C D 4 5 6` —— 命中

**1.4.1** 因为 `A B C D` 完全一样：

```
h1_D 一样  →  K2_D、V2_D 一样  →  缓存命中 ✅
```

**1.4.2** 于是 **D 之前的整段都不用重算**，只算后面 `4 5 6`。

**1.4.3** **这就是"前缀缓存"。** ✅

## 1.5 换成 X：`X B C D` —— 内容变了

**1.5.1** 注意：**D 这个 token 自己没变，D 的位置也没变**（还是第 4 位）。

**1.5.2** 但 D 的注意力要重算：

```
q_D 不变 = [2,0]
key 们： X→4.243   B→0   C→1.414   D→2.828
exp: 69.57, 1.000, 4.113, 16.912    和=91.60
α: 0.760, 0.011, 0.045, 0.185
h1_D = 0.760·[3,0] + 0.011·[0,1] + 0.045·[1,1] + 0.185·[2,0]
     = [2.69, 0.06]        ← 从 [1.61, 0.20] 变了！
```

**1.5.3** 于是第 2 层：

```
K2_D :  [1.61, 0.20]  →  [2.69, 0.06]      变了！
V2_D :  同样变了
```

**1.5.4** 看清楚：

```
D 自己没变、D 的位置没变  ——  但 D 的 K/V 变了
为什么？因为 D 前面那个 token 的内容变了
```

**1.5.5** **这就是"内容依赖"存在的铁证。**

**1.5.6** 更狠的是：变的**不是"某个 token 的那一份"**，而是**整排权重都重排了**。
因为 softmax 是 `exp(s_ij) ÷ (所有 s 的 exp 之和)` —— **分母里含每一个 key**。

**1.5.7** 顺带：变的**只是第 2 层**。第 1 层的 D **没变**（它只看自己）。→ 见 `1.7`。

## 1.6 插入 Z：`Z A B C D` —— 位置变了

**1.6.1** 这一次，**A 的位置从"第 0 位"变成了"第 1 位"**。

**1.6.2** 如果模型带"位置信息"，那么：

```
A 的输入 = 向量(A) + 位置(0)   →   向量(A) + 位置(1)    变了
→ h1_A 变 → 后面全跟着变
```

**1.6.3** 于是两件事被**分开**了：

```
【1.5 换掉 A：等长替换】  位置没变，只有内容变  →  变的是"内容依赖"
【1.6 最前面插入 Z】      位置整体后移          →  变的是"位置信息"
```

**1.6.4** 一个只动内容、一个只动位置——**两只手，分开了。**

## 1.7 【关键】依赖是怎么一层层叠上去的

**1.7.1** 先看一张表（这就是整件事的核心）：

| 位置 | **第 1 层** K/V 依赖谁 | **第 2 层** K/V 依赖谁 |
|---|---|---|
| A | 只有 A | A |
| B | 只有 B | **A、B** |
| C | 只有 C | **A、B、C** |
| D | 只有 D | **A、B、C、D** |

**1.7.2** 为什么第 1 层是"纯净的"？

```
第 1 层的输入 = 嵌入（每个 token 各是各的，谁也还没碰过谁）
注意力混合，发生在"算完 Q/K/V 之后"
→ 所以第 1 层的 K/V 还没被邻居影响
```

**1.7.3** 但接着就发生"叠加"了：

```
第1层：K1_C = 只看 C
第1层输出 h1_C = 注意了 A、B、C 的 V1      ← A、B 在这里进来
第2层：K2_C = 由 h1_C 算来               ← 于是"含有"A、B  ✅
```

**1.7.4** 一句话：

> **层数 = 记忆的深度。** 每多一层，每个位置就"多回头记一个级别"。
> 所以是**多层堆叠**，最终把"可复用单位"逼成了**最长公共前缀**。

## 1.8 元凶在公式里是哪一块

**1.8.1** 把公式摊开，标出"谁负责哪件坏事"：

```
x_j      = 嵌入(token_j) + 位置(j)          ← 【元凶②】位置在这里进来
q_i, k_j, v_j = x·W_Q, x·W_K, x·W_V
s_ij     = (q_i · k_j) / √d                 ← 【元凶①-a】内容在这里"被比较"
α_ij     = softmax(s_ij)                    ← 【元凶①-b】分母含【所有】key
output_i = Σ_j α_ij · v_j
```

**1.8.2** 两个元凶，各管一件事：

| 元凶 | 在公式里的位置 | 它导致 |
|---|---|---|
| **① 内容耦合** | `q_i · k_j`（比较内容）+ `softmax` 的**分母** | **替换** token → 缓存失效 |
| **② 位置依赖** | `x_j` 里的 `+ 位置(j)` | **插入** token → 缓存失效 |

**1.8.3** 但要注意：**它们不是各管一半、互不相干**——
替换 token 如果改变了长度，位置也一起变；而且因为**分层堆叠**，任何一处变化都会往上传递。

**1.8.4** 其中 **softmax 的分母**，是"一改全改"的直接原因：

```
α_ij = exp(s_ij) ÷ ( exp(s_i1) + exp(s_i2) + … )
                     └────── 分母里有【每一个】key
→ 改一个 key → 分母变 → 这一排【所有】α 都变
```

**1.8.5** 一句话总结元凶：

> **"每个位置的值，由『内容 ⊕ 位置』决定；而且后面的位置依赖前面的全部。"**
> —— 换成内容（元凶①）会废、挪了位置（元凶②）也会废。

## 1.9 如果没有元凶：还能复用，只是"麻烦点"

**1.9.1** 问题：把元凶拿掉，是不是就没法缓存了？

**1.9.2** 答案：**不。还能缓存，而且能复用得【更多】——但查法得改，账也得自己记。**

**1.9.3 假设去掉 ① 内容耦合**（让 α 不互相纠缠，贡献可以相加）：

```
原本：softmax 让一排 α 互相纠缠 → 一个变、整排变 → 只能整段作废
去掉：每个 token 的贡献【独立、可加】
  → 缓存可以【增、删、改】，而不是"一改全废"
  → 这就是【线性注意力】的"可累加状态"
```

**麻烦点**：① 得自己维护一个"累加状态"；② 丢掉"谁跟我像就多听谁"的能力。

**1.9.4 假设去掉 ② 位置依赖**（让 K/V 只跟 token 有关）：

```
有位置：同一 token 出现在不同位置 → K/V 不同
去掉：  同一 token 出现在【任何】位置 → K/V 都一样
```

**示例**：

```
请求3: P Q B C R
请求4: Z B C W
         ↑ "B C" 出现在不同位置（请求3 是第 2、3 位；请求4 是第 1、2 位）

有位置项：  B 的位置不同 → 输入不同 → K1_B 不同 → 不能复用
没有位置项：B 的输入 = 嵌入(B) → 两个请求一样 → K1_B 相同 → 可以复用 ✅
```

**麻烦点**：① 不能再用"前缀链"查，得改成**按 token 查**；
② 这**只在第 1 层成立**——第 2 层还受元凶① 绑着，所以还得再想办法。

**1.9.5** 结论：

```
去掉元凶 → 可复用范围【变大】
         → 但缓存单位从"前缀"变成了"集合 / 累加状态"
         → 查法、账法都要重写  ← 这就是"麻烦点"
```

# 第二部分：点名（例子里的东西都叫什么）

## 2.1 名词对照

| 例子里的东西 | 术语 | 一句话解释 |
|---|---|---|
| `1.2` 那三步 | **注意力** | 每个位置回头看前面的内容 |
| `[1,0]` 这种向量 | **嵌入** | token 变成的数 |
| `K2_D`、`V2_D` | **K / V** | 缓存里存的就是它们 |
| 我们**没存**的东西 | **Q** | 只服务当前，用完就扔 |
| "第 2 层" | **层** | 每层各自有 K/V，要分层存 |
| `1.5` 里 D 的变化 | **内容依赖 / 因果依赖链** | 前面变 → 后面变 |
| `1.6` 里 A 的变化 | **位置信息（位置编码）** | 移位 → 值变 |
| `1.4` 那个"命中" | **前缀缓存** | 开头一样就能复用 |
| "存下来不重算" | **KV cache** | 缓存本身的名字 |
| 分块 + 哈希查表 | **vLLM 的块哈希链** | 怎么找到命中的 |
| "可累加的运行状态" | **线性注意力** | 另一条路，不需要存全部 KV |
| `1.2.1` 第②步的 softmax | **非线性 + 耦合的来源** | 分母含所有 key → 一处变、处处变 |

## 2.2 每个数字「被谁影响、为什么关键」（定性）

| 数据 | 谁影响它 | 变了意味着什么 |
|---|---|---|
| `V1_A`（第 1 层 A 的 V） | 只有 **A 自己和它的位置** | 换 A、挪 A → 它变 |
| **`h1_D`** | **A、B、C、D 全都有份**（注意力加权） | 前面任何一个动 → 它动 ← **关键** |
| **`K2_D` / `V2_D`** | 由 `h1_D` 决定 → 于是"含有" A~D | **D 没变、位置没变，它也会变** ← **决定性** |
| 位置号 | 插 / 删 token | 后移 → 后面所有位置的值全变 |

## 2.3 这份文档要你记住的一句话

**2.3.1** 缓存存的，是**每层每个位置的 K 和 V**。

**2.3.2** 一个位置的 K/V **会不会变**，取决于：

```
① 它前面某个 token 的【内容】变了没      → 1.5 演示
② 它自己的【位置】挪了没                → 1.6 演示
```

**2.3.3** 而且**层越深，它"含"的前面信息越多**（见 `1.7` 那张表）。

**2.3.4** 所以"能复用的，只有从头开始、内容和位置都一样的"那一段。
**→ 这就是"必须是前缀"。**
