# schema 版本与迁移记录（Migration Log）

> 铁律：**制式只加不破**。新版 = 旧版 **超集**；旧版必须被**认识**（校验器给 warning 不报错），
> 并可用 `0_migrate_schema.py` **升级**；升级后**全链跑通**。

---

## 版本定义

| 版本 | 列 | 说明 |
|---|---|---|
| **v1** | `关系, 值域, 口径, 可否对比, 备注` | 旧版（无"层级/语义"） |
| **v2** | `关系, 值域, 口径, 适用层级, 语义, 可否对比, 备注` | 现行（D-4：加 `适用层级`+`语义`） |

**v2 = v1 + 两列**（`适用层级`、`语义` 插在 `口径` 后）。**列名/取值只增不改**。

---

## 迁移规则 v1 → v2（`0_migrate_schema.py` 自动执行并留痕）

| 新列 | 缺省填法（按 `关系` 关键词） |
|---|---|
| `适用层级` | 默认 `SPU`；命中 `命名/别名/定位/代际/系列/共享` → `系列` |
| `语义` | 默认 `事实`；命中 `命名/别名/代际/规则` → `规则`；命中 `全称/共享` → `全称`；命中 `定位` → `典型` |
| `可否对比` | 已有则保留，无则 `0` |

**留痕**：每次迁移写 `*.migrate.md`（逐行记录填了什么、为什么），并可归档进本文件下方"迁移历史"。

## 怎么用（公司里）
```powershell
# 旧表不认识 → 先迁移（留痕），再校验
python tools\0_migrate_schema.py --schema input\schema_手机_v1.csv --out input\schema_手机.csv
python tools\0_validate_schema.py --schema input\schema_手机.csv
# 直接拿旧表跑校验也不会炸：会提示"检出 v1，可迁移"
python tools\0_validate_schema.py --schema input\schema_手机_v1.csv
```
