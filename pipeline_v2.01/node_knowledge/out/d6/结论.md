# D-6 实验结论：CoT「通用写法」 vs 「按题型分步」

- **样本**：9 题（1-1×2、1-2×2、2-3×2、L2×1、3-1×2）
- **控制变量**：同一【知识结构】；**只变【推理】段的写法**
  - A = 现状通用问法（`4_gen_cot.py`：先定位分支、再引用要点、得出结论）
  - B = D-6 按题型推理路径**分步**
- **产物**：`cot_a.jsonl` / `cot_b.jsonl` / `compare.html`

## 观察
1. **正确性**：两者基本都对（因为答案已给）；**差异在"过程"不在"结果"**。
2. **可核验性**：**B 明显更好**——每步点名"定位哪个实体 / 取哪个关系 / 比较谁"，可逐步对回知识结构；A 压成一句，跳步是**隐式**的。
3. **多跳 3-1**：**B 是 4 步**（定位→上溯→取父层→结论），**可每跳计分**；A 一句话，**无法分跳**。→ 多跳题几乎必须用 B。
4. **L2 规则题**：B 显式走"系列规则适用 → 命名排除 → 否定"；A 虽对，但没点出规则适用链。
5. **上游依赖（关键）**：B 会把"本题涉及哪些实体/关系"的**抽取错误显形**（实验初版出现占位符「B」，因漏配 `Mate 80`）；**A 会掩盖它**（用模型自身知识补上，看着对但不 grounded）。

## 结论
- **采纳 D-6**：CoT 按题型分步；**3-1 / 2-5 / L2 收益最大**。
- **前置条件**：修好"本题涉及实体/关系"抽取（**长名优先 + 命中即移除**，已修）。
- **落地**：`推理路径.json`（type→步骤）+ `4_gen_cot.py --paths`；**无模板则回落通用**。

## 待办 / 已知问题
