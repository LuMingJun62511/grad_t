# 大表整理建议 · 手表

- 产品 **10** 款，列 **26** 个。

## 原则
- **列 = 跨产品可比的元属性**；只有个别款有的东西 → 进 `特性`（多值），**不单开列**。
- **一列一概念、一口径**（口径写进 schema 的「口径」列）。
- **核心列应对所有款有值**（缺的 = 待补）。

## ① 核心列（≥80%，应保持必填）  0 个
