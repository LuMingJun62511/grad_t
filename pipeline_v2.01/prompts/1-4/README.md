# 1-4 真伪确认

## 题型定义

信息结构：**题目给 S + O，题点是 R 是否成立，答案是 是/否**。
用途：台阶一训练主力。肯定样本教确认，否定样本教模型"不顺着题目瞎编"——知识边界由此划定。
否定样本的"错误值"取自同关系下其他实体的真实值（非编造）。

## 模板池（runner 轮换用，LLM 不可见）

1. "{S}是{O}吗？"
2. "{S}是否{O}？"
3. "{S}{O}，对吧？"
4. "{S}用的是{O}吧？"

## 输入格式

```json
{"entity": "Mate 80 Pro", "tree_path": "...", "items": [
  {"relation": "搭载芯片", "value": "麒麟9030", "truth": true},
  {"relation": "搭载芯片", "value": "麒麟9020", "truth": false}
]}
```

## 输出示例

```json
{"question": "Mate 80 Pro 是搭载麒麟9030吗？", "answer": "是"}
{"question": "Mate 80 Pro 用的是麒麟9020吧？", "answer": "不是"}
```

## 质量自检

- [ ] 肯定/否定答案与 truth 严格一致？
- [ ] 否定样本的值确实来自其他真实实体（非编造）？
- [ ] 题目含产品全名和属性值，且不泄露真假标记？
