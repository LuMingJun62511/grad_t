# 2-1 反向指代

## 题型定义

信息结构：**题目指向宾语 O（用值指代实体），题点是 R，答案是主语 S**。
用途：台阶二评测核心。训练时教正向（1-1），评测时考反向——模型必须把知识反转使用。
前置条件：O 必须独有（input 中 unique_triples 已筛选），答案唯一。

## 模板池（runner 轮换用，LLM 不可见）

1. "哪款产品的{R}是{O}？"
2. "{R}为{O}的是哪款产品？"
3. "哪款产品在{R}上是{O}？"
4. "什么产品的{R}是{O}？"

## 输入格式

```json
{"entity": "Mate 80 Pro Max", "tree_path": "...", "unique_triples": [{"relation": "屏幕", "value": "超透亮灵珑屏"}]}
```

## 输出示例

```json
{"question": "哪款产品的屏幕是超透亮灵珑屏？", "answer": "Mate 80 Pro Max"}
```

## 质量自检

- [ ] 题目中无产品名（指代成立）？
- [ ] 属性值原样出现在题目中？
- [ ] 答案是唯一确定的产品全名？
- [ ] 该问法在台阶一训练中从未出现？
