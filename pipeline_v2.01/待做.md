## E. 耳机全量重跑（命令链草案）
```powershell
$env:ANTHROPIC_BASE_URL=...; $env:ANTHROPIC_AUTH_TOKEN=...; $env:DS_MODEL=deepseek-v4-flash
$IN="input\耳机"; $PKG="out\耳机"
python tools\0_validate_data.py --data "$IN\数据.jsonl" --tree "$IN\tree.json"   # 校验前置
python tools\0_validate_schema.py --schema "$IN\schema_耳机.csv"
python tools\2_gen_scpt.py --data "$IN\数据.jsonl" --category 华为耳机 --outdir "$PKG\scpt"
python tools\3b_gen_questions_template.py --data "$IN\数据.jsonl" --outdir $PKG --suggest "$IN\出题建议.csv" --category 华为耳机
foreach ($t in '1-1','1-2','1-3','1-4','2-1','2-2','2-3','2-4','2-5','2-6','L1','L2','3-1') {
  if (Test-Path "$PKG\$t.jsonl") { python tools\4_gen_cot.py --questions "$PKG\$t.jsonl" --data "$IN\数据.jsonl" --out "$PKG\cot\$t.jsonl" --style raw } }
# —— 选择性组装试验 ——
python tools\4b_cot_restyle.py --cot "$PKG\cot\1-1.jsonl" --style short --out "$PKG\cot_short\1-1.jsonl"
python tools\5_assemble_sft.py --pkg $PKG --output-mode short
python tools\6_make_review.py --pkg $PKG --title 耳机
```
> 注：`input\耳机` 需含 `数据.jsonl` / `tree.json` / `schema_耳机.csv` / `出题建议.csv`；`3-1` 待出题器就绪。
