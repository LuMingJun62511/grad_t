# schema 草稿（待你定）

> 目标：把 **节点级（系列/代）知识** 纳入 schema，并给**每条产线**一套**统一结构**的 schema。
> 用法：**我出可选范围，你勾选/增删**；定稿后再落成各产线的"元特性表"。

---

## A. 节点级（系列/代）知识 · 候选字段

| # | 字段（谓语） | 说明 | 值域（**可选范围**，你定） | 语义 | 建议 |
|---|---|---|---|---|---|
| N1 | **命名后缀** | 该系列出现过的后缀（白名单） | 见 §B | 规则 | ✅ 你点名要 |
| N2 | **命名排除** | 明确不出现的后缀（黑名单） | 见 §B | 规则 | ✅（Ultra 这类） |
| N3 | **系列别名** | 系列的别称/简称 | 自由 | 规则 | ✅ 你点名要 |
| N4 | 系列定位 | 商务/时尚/入门… | 枚举（各家自定） | 典型 | 可选 |
| N5 | 全称特性 | **全系都成立**的特性 | 同 schema 谓语 | **全称** | ✅ 能出 L3 |
| N6 | 代际命名规则 | 数字/年份递进规则 | 自由 | 规则 | 可选 |
| N7 | 共享平台/芯片 | 全系同款 | 芯片名 | 全称 | 可选 |

> 语义三分：`全称`（成员可继承→出 L3）/`典型`（仅背景）/`规则`（出 L2 否定题）。

## C. 产线 schema **统一模板**（所有产线同构）

```
schema_<产线>/
├─ 通用谓语       # 跨产线：发布时间、售价、配色、重量/尺寸、定位、状态…
├─ 品类谓语       # 该产线专属：手机=芯片/屏幕/电池；耳机=降噪/续航；笔记本=处理器/内存…
└─ 节点级谓语     # N1-N7（命名后缀、别名、全称特性…）
```
每个谓语字段统一带：`值域 / 口径 / 语义(全称|典型|规则) / 可否出对比`。
