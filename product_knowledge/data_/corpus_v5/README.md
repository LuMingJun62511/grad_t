# 语料 V5 — 百科原文整理工作区

> 小范围验证: Mate 系列手机 (23 SPU) + 耳机全系 (11 SPU)
> 流程: 百科原文 → 大模型整理为结构化MD → 切片 → SCPT/SSFT 数据

---

## 一、目录

```
corpus_v5/
├── README.md          ← 本文件 (工作规范)
├── raw/               ← 你手动粘贴的百科原文 (原始形态)
├── baike_md/          ← 整理后的MD (按「代」为单位, 待切片)
└── small_subset.json  ← 产品子集清单 (34个SPU)
```

## 二、工作流程

```
① 你粘贴百科原文 → raw/ 目录, 每篇一个 txt/md
     命名: {系列}_{代}_百度百科.txt  例: Mate_80系_百度百科.txt

② 我用大模型整理 → baike_md/ 目录
     结构: 按章节组织, 每节 200-500 字, 适合后续切片

③ 切片 → chunk + 知识路径 (对应产品树节点)

④ 生成训/推数据 (SCPT + SSFT)
```

## 四、MD 整理格式 (大模型整理目标)

```markdown
# {百科词条名}

> 来源: 百度百科 | 整理日期: 2026-08-12

## 系列概述
{2-3段, 该系列的整体定位、发布时间、市场背景}

## 产品矩阵
{列出该代下所有SPU及其一句话定位}

## 各型号详解
### {SPU名}
{该型号的核心参数、特色功能, 200-400字}

## 技术亮点
{芯片、屏幕、影像、通信等维度的技术说明}

## 市场反响
{销量、评价、话题度等}
```

## 五、切片规则 (后续)

- 每节 (##) 切为一个或多个 chunk (≤500字)
- 每个 chunk 带知识路径: `华为 > 手机 > Mate系 > Mate 80系`
- SPU 级别的 chunk 路径精确到: `... > Mate 80系 > Mate 80 Pro`
