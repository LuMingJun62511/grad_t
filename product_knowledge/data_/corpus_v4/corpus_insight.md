## 五、缺失分析

### 缺失的头部产品

| 产品 | 原因 |
|------|------|
| Mate 80 (标准版) | 百度百科词条太短，被过滤 |
| Mate 80 Pro Max 风驰版 | 小众SKU，新闻少 |
| Mate X8 / Mate XT2 | 未发布，无内容 |
| WATCH Ultimate 2 / D2 | 小众品类，snippet空 |
| FreeBuds 全系 | 耳机类snippet短，被过滤 |
| 智能汽车全系 | 百度搜索匹配差 |

### 根本原因

百度搜索 snippet 的信息量天然受限于：
1. **产品知名度** — 旗舰Pro/Max版搜得到，标准版/SE版搜不到
2. **品类特征** — 耳机/手表/汽车在百度搜索的文本密度远低于手机
3. **时效性** — 旧代产品（2020-2023）的新闻/评测已被新内容淹没
4. **百度反爬** — 频繁搜索触发了IP限流，部分关键词返回空页

## 七、下一步建议

1. **手机品类已够用** — Mate/Pura/折叠屏/nova旗舰的语料质量好、覆盖全
2. **缺失品类需补** — 智能汽车(0篇)和耳机/手表要用产品树扩写
