# 脚本使用指南

## 环境要求

- Python 3.8+
- 无第三方依赖（仅标准库：json, re, random, sys, collections）

---

## 一、gen_eval.py — 评测集生成

### 用途

从产品 JSON 生成实体链接评测集。模板驱动，答案精确可控，不需要人工打分。

### 用法

```bash
# 基本用法
python script_/gen_eval.py <产品JSON路径> [输出路径] [选项]

# 生成华为评测集（692条）
python script_/gen_eval.py data_/华为产品属性.json data_/评测集.jsonl

# 换公司用
python script_/gen_eval.py data_/小米产品属性.json data_/小米评测集.jsonl

# 调参：更多条目、不同随机种子
python script_/gen_eval.py data_/华为产品属性.json data_/评测集.jsonl --max 150 --seed 123

# 只跑某一类生成器
python script_/gen_eval.py data_/华为产品属性.json data_/评测集.jsonl --gen 别名直接查询
```

### 参数

| 参数 | 说明 | 默认值 |
|------|------|--------|
| `<产品JSON>` | 产品属性 JSON 路径（必填） | — |
| `[输出路径]` | 评测集输出路径 | `eval_corpus.jsonl` |
| `--max N` | 每种生成器最多 N 条 | 80 |
| `--seed N` | 随机种子 | 42 |
| `--gen <名称>` | 只跑指定生成器 | 全部 |

### 生成器类型

别名直接查询、别名在句中使用、定位标签反查、话题锚点反查、价格查询、品类枚举、状态查询、代际查询、同系列对比、极限数字反查。

### 输出格式

```json
{"input": "什么叫三折叠?", "output": {"company": "华为", "entities": {"三折叠": "Mate XTs 非凡大师"}}, "_generator": "别名直接查询"}
```

`_generator` 字段记录来源，方便按类型分析评测结果。

## 二、gen_train.py — 训练语料生成（模板版）

### 用途

从产品 JSON 生成 SFT 训练语料。模板填充，风格正式但覆盖全面。适合快速生成基线训练数据。

### 用法

```bash
# 基本用法
python script_/gen_train.py <产品JSON路径> [训练语料输出] [LLM种子输出] [选项]

# 生成训练语料 + LLM 扩增种子
python script_/gen_train.py data_/华为产品属性.json data_/训练语料.jsonl data_/种子.jsonl

# 更多条目
python script_/gen_train.py data_/华为产品属性.json data_/训练语料.jsonl --max 150
```

### 参数

| 参数 | 说明 | 默认值 |
|------|------|--------|
| `<产品JSON>` | 产品属性 JSON 路径（必填） | — |
| `[训练语料输出]` | 训练语料输出路径 | `train_corpus.jsonl` |
| `[LLM种子输出]` | LLM 扩增种子输出路径 | `llm_seeds.jsonl` |
| `--max N` | 每种生成器最多 N 条 | 120 |
| `--seed N` | 随机种子 | 42 |

### 生成器类型（10种）

别名消歧、产品介绍、品类枚举、系列枚举、价格查询、反向查找、同系列对比、折叠屏专题、极限之最、状态查询。

### 输出格式

```json
{"instruction": "三折叠是啥?", "output": "三折叠指的是Mate XTs非凡大师, 华为手机, 超高端商务/三折叠, 主打10.1寸展开当平板用、PC级应用, 售价¥18000起。"}
```

同时生成 `llm_seeds.jsonl`，包含模板无法覆盖的 6 种语料类型的种子提示词（output 为空），供 LLM 批量扩增。

## 三、merge_train.py — 多路 LLM 输出合并

### 用途

将多个 Agent 生成的训练语料文件合并，去重，打乱，输出单一训练集。

### 用法

```bash
python script_/merge_train.py <agent输出1> <agent输出2> ... -o <输出路径>

# 示例：合并三路输出
python script_/merge_train.py \
    _phone_train.jsonl \
    _other_train.jsonl \
    _cross_train.jsonl \
    -o 训练语料_合并版.jsonl
```

### 参数

| 参数 | 说明 |
|------|------|
| `<文件1> <文件2> ...` | 待合并的 Agent 输出文件（不限数量） |
| `-o <路径>` | 合并输出路径 |

### 功能

- 从 Agent 输出文件中提取 `{"instruction": ..., "output": ...}` 格式的 JSONL 行
- 按 instruction 去重（相同问题只保留一条）
- 随机打乱
- 输出统计：原始条数、去重后条数、重复数

## 完整工作流

### 第一次使用（新公司/新产品线）

```bash
# Step 1: 按 schema 准备产品 JSON（手动或用爬虫/脚本）
# 文件: data_/XX产品属性.json

# Step 2: 生成评测集
python script_/gen_eval.py data_/XX产品属性.json data_/XX评测集.jsonl

# Step 3: 生成模板版训练语料 + LLM种子
python script_/gen_train.py data_/XX产品属性.json data_/XX训练语料_模板版.jsonl data_/XX种子.jsonl

# Step 4: 用 LLM 生成自然版（参考 design/设计思路.md 的 Agent 分流方案）
# 或根据 XX种子.jsonl 批量让 LLM 填充 output

# Step 5: 合并
python script_/merge_train.py _phone.jsonl _other.jsonl _cross.jsonl -o data_/XX训练语料_自然版.jsonl
```

### 更新产品数据后

重新跑 Step 2-4，评测集确保不出错，训练语料追平最新产品。
