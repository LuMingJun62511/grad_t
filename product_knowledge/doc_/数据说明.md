# 数据说明

## 数据文件清单

### 1. 华为产品属性.json（输入源）

路径：`data_/华为产品属性.json`

唯一的数据源文件。89 个产品，覆盖 10 个品类。

**字段 schema：**

| 字段 | 类型 | 说明 | 示例 |
|------|------|------|------|
| company | string | 公司名 | "华为" |
| category | string | 一级品类 | "手机" / "平板" / "智能手表" |
| series | string | 二级产品线 | "Mate 系列" / "折叠屏" |
| sub_series | string/null | 三级代际 | "Mate 80 系列" / null |
| name | string | 正式产品名（唯一标识） | "Mate 80 Pro Max" |
| alias | string[] | 所有别名/俗称/缩写 | ["M80PM", "Mate80超大杯"] |
| positioning | string[] | 定位标签 | ["商务旗舰", "顶配影像"] |
| talking_points | string[] | 话题锚点 | ["双潜望长焦", "双层OLED"] |
| generation | string | 代际状态 | "最新款" / "上代" / "即将发布" |
| price | string | 价格 | "¥7499起" / "待补充" |
| status | string | 销售状态 | "在售" / "即将发布" |

**品类分布：**

| 品类 | 产品数 |
|------|--------|
| 手机 | 37 |
| 平板 | 9 |
| 笔记本 | 8 |
| 智能手表 | 10 |
| 耳机 | 4 |
| 音箱 | 2 |
| 智慧屏 | 4 |
| 智能眼镜 | 1 |
| 显示器 | 1 |
| 智能汽车 | 10 |

### 2. 华为评测集.jsonl

路径：`data_/华为评测集.jsonl`

格式：JSONL，每行一个评测用例。

```
{"input": "自然语言问句", "output": {"company": "华为", "entities": {提及: 产品名}}}
```

**评测类型分布（692条）：**

| 类型 | 条数 | 考察能力 |
|------|------|----------|
| 别名直接查询 | 80 | "M80PM是什么?" → 产品全称 |
| 别名在句中使用 | 80 | "想换三折叠" → 实体抽取 |
| 定位标签反查 | 80 | "商务旗舰有哪些?" → 产品列表 |
| 话题锚点反查 | 80 | "麒麟9030的机型?" → 产品定位 |
| 价格查询 | 80 | "Mate XTs多少钱?" → 价格 |
| 品类枚举 | 47 | "华为折叠屏有哪些?" → 全品类 |
| 状态查询 | 80 | "还在卖吗?" → 在售状态 |
| 代际查询 | 66 | "是最新款吗?" → 代际确认 |
| 同系列对比 | 80 | "Mate 70 Pro和RS啥区别?" → 多重属性 |
| 极限数字反查 | 19 | "最贵的手机?" "798g的笔记本?" |

生成方式：`python script_/gen_eval.py data_/华为产品属性.json data_/华为评测集.jsonl`

---

### 3. 华为训练语料.jsonl（模板版）

路径：`data_/华为训练语料.jsonl`

格式：JSONL，每行 `{"instruction": "问题", "output": "回答"}`

807 条，10 种类型。回答为模板拼接，风格正式但偏机械。

**适用场景：**快速基线、规则验证、数据格式参考。

---

### 4. 华为训练语料_自然版.jsonl（推荐 ★）

路径：`data_/华为训练语料_自然版.jsonl`

格式：同模板版。608 条，零重复。

三路 LLM Agent 并行生成：手机 214 + 其他品类 221 + 跨品类 173。

**相比模板版的提升：**
- 回答口语化，有观点有态度
- 覆盖跨品类对比（手机vs平板等）、话题闲聊（发布会、大嘴、制裁后现状）
- 支持模糊口语（"华子"、"三折的"、"夹耳朵上那个"）
- 包含场景推荐（出差、送长辈、学生党、健身等）
- 纠错消歧（"Mate 90 还没出"、"你说的5折应该是折叠屏吧"）

---

### 5. llm_seeds.jsonl

路径：`data_/llm_seeds.jsonl`

19 条种子提示，output 为空。标注了模板无法生成的 6 种语料类型，可作为 LLM 批量扩增的输入。

**类型：**跨品类对比、话题闲聊、模糊口语匹配、纠错消歧、竞品对比、用户场景推荐。

---

## 数据演进链路

```
华为产品树.md（人工整理）
    │
    ▼
华为产品属性.json（结构化，一产品一对象）
    │
    ├──→ gen_eval.py ──→ 华为评测集.jsonl（692条，实体链接任务）
    │
    ├──→ gen_train.py ──→ 华为训练语料.jsonl（807条，模板版）
    │
    └──→ LLM Agent 三路并行 ──→ 华为训练语料_自然版.jsonl（608条，自然版）
              │
              └── 种子提示参考 llm_seeds.jsonl
```
