# 1-1 正向属性询问

## 文件约定

```
prompt.txt    ← 纯 prompt 正文 (含 {S}/{R}/{O}/{TEMPLATE} 占位符), 可直接使用
README.md     ← 本文件: 题型说明/输入格式/模板池/质量自检
input.jsonl   ← 输入 (每行一个实体包)
output.jsonl  ← 输出 (每条一行: entity/relation/value/raw/status)
审阅.xlsx     ← 人工审阅用
```

## 题型定义

信息结构：**题干指向主语，考点是谓语，答案是宾语**。
台阶一训练主力。

## 模板池（runner 轮换用，LLM 不可见）

1. "{主语}的{谓语}是什么？"
2. "{主语}用的{谓语}是啥？"
3. "{主语}的{谓语}呢？"
4. "{主语}{谓语}是啥？"

## 输入格式

```json
{"entity": "Mate 80 Pro", "tree_path": "...", "triples": [{"relation": "搭载芯片", "value": "麒麟9030"}]}
```

## 质量自检

- [ ] 题干指主语？考点是谓语？答案=宾语逐字一致？
- [ ] 题目+答案连读通顺？
- [ ] 严格使用指定模板？
