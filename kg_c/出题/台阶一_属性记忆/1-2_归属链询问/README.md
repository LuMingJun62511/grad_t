# 1-2 归属链询问

## 题型定义

信息结构：**题目指向主语 S，题点是 is_a 层级，答案是层级名**。
用途：台阶一训练主力，建立树纵向认知。同一实体可向上追问多层（代→系列→产线→品类）。

## 模板池（runner 轮换用，LLM 不可见）

1. "{S}属于哪个层级？"
2. "{S}属于什么？"
3. "{S}是哪个层级的产品？"
4. "{S}归在哪个层级下面？"

## 输入格式

```json
{"entity": "Mate 80 Pro", "tree_path": "...", "triples": [{"relation": "is_a", "value": "Mate 80 系列"}]}
```

## 输出示例

```json
{"question": "Mate 80 Pro 属于哪个系列？", "answer": "Mate 80 系列"}
```

## 质量自检

- [ ] 题干指主语？考点是层级？
- [ ] 问句层级词与答案层级一致（答案带"系列"问"系列"）？
- [ ] 答案=层级名逐字一致？
- [ ] 题目+答案连读通顺？
