# 1-3 属性集合枚举

## 题型定义

信息结构：**题目指向主语 S，题点是 R，答案是 O 的全集**。
用途：台阶一训练主力，考完整性——同一实体同一关系的多个值必须答全，训练模型"不只想起第一个答案"。

## 模板池（runner 轮换用，LLM 不可见）

1. "{S}有哪些{R}？"
2. "{S}的{R}都有什么？"
3. "{S}的{R}有哪几种？"
4. "{S}{R}都有哪些可选？"

## 输入格式

```json
{"entity": "Mate 80", "tree_path": "...", "multi_groups": [{"relation": "产品定位", "values": ["商务旗舰", "直屏旗舰"]}]}
```

## 输出示例

```json
{"question": "Mate 80 有哪些产品定位？", "answer": "商务旗舰、直屏旗舰"}
```

## 质量自检

- [ ] 问句暗示"多个答案"（哪些/都有什么）？
- [ ] 答案与取值全集逐一对应，无遗漏无增改？
- [ ] 取值顺序与输入无关（顿号连接，顺序可换）？
