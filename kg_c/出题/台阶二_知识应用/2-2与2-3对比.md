# 2-2 多条件筛选 vs 2-3 同代横向对比

> 两者都涉及多个实体，但**信息流方向相反**，数据组织方式根本不同。这是区分它们的关键。

---

## 一、核心对比表

| 维度 | 2-2 多条件筛选 | 2-3 同代横向对比 |
|------|---------------|-----------------|
| 信息流 | 属性值 → 实体集合 | 两个实体 → 属性差异 |
| 题目给什么 | 条件（属性=值）+ 范围 | 两个实体名 |
| 题目不给什么 | 实体名 | 属性值 |
| 答案是什么 | 实体列表（子集） | 差异描述（值对） |
| 考的运算 | 集合交集 / 过滤 | 求异 / 比对 |
| 题例 | "手机品类中，哪些机型搭载麒麟9030 Pro？" | "Mate 80 和 Mate 80 Pro 的芯片有什么区别？" |
| 答案例 | "Mate 80 Pro Max、风驰版、RS 非凡大师" | "Mate 80 是麒麟9020，Pro 是麒麟9030" |

## 二、数据组织的根本区别

```
2-2: 倒排索引 (以宾语为根)
   scope(品类) → 关系 → 值 → [主语集合]
   "麒麟9030 Pro" → ["Mate 80 Pro Max", "风驰版", "RS"]
   ↑ 真值存在倒排表里, 出题和核验都从这里走
   ↑ 没有倒排组织, "哪些"的完整答案无从知道

2-3: 实体对 (以实体为根)
   同代实体两两配对 → 比对同关系下的值 → 找不同
   (Mate 80, Mate 80 Pro) → 芯片: 9020 vs 9030 → 出差异题
   ↑ 真值是"值对", 存在配对关系里
```

**一句话**：2-2 从宾语出发组织（n 叉展开找主语），2-3 从实体对出发组织（两两配对找值差）。

## 三、核验方式对比

| | 2-2 | 2-3 |
|---|-----|-----|
| 真值来源 | 倒排索引的实体集合 | 两实体的属性值对 |
| 评分 | 列表 F1（集合比对） | exact match（差异描述比对） |
| 无倒排/无配对时 | 无法核验"哪些"的完整性 | 无法核验差异两侧的值 |

## 四、与 2-1 的关系

```
2-1: 双条件交集 = 1 个实体  → 锁唯一（答1个）
2-2: 条件交集 = 2~N-1 个    → 筛子集（答多个）
2-3: 无条件点名两实体        → 比差异（答值对）
```

2-2 是 2-1 的"非唯一"版本；2-3 与两者都不同——它不靠条件驱动，靠点名驱动。

## 五、题量瓶颈的位置

| 题型 | 瓶颈在哪 | 数据大了以后 |
|------|---------|-------------|
| 2-2 | 倒排索引里主语数落在 2~N-1 的组合数（本地语料仅 7 组） | 品类实体多，可筛组合指数增长 |
| 2-3 | 同代实体的配对数和同关系异值的数量 | 一个系列 5+ 个 SKU，配对增长 C(n,2) |

本地小语料两者都贫血，但贫血的位置不同：2-2 贫在"值有区分度"，2-3 贫在"配对同关系可异值"。
