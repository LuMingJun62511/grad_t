# Prompt: 2-4 代际纵向对比

## 题型定义

信息结构：**题目指向同系列的不同代，题点是跨代属性变化，答案是变化描述**。
用途：台阶二评测。用上产品树的"代"层——新旧对比是真实用户高频问题。两代的属性在台阶一单独训练过。

前置条件：同系列两代，同一属性 R 在两代都有值且不同。

## 输入格式 (JSON)

```json
{
  "old_gen": {"name": "Mate 70 Pro", "attributes": [{"relation": "搭载芯片", "value": "麒麟9020"}]},
  "new_gen": {"name": "Mate 80 Pro", "attributes": [{"relation": "搭载芯片", "value": "麒麟9030"}]},
  "tree_path": "华为 > 手机 > Mate 系"
}
```

## 输出示例

```json
[
  {"relation": "搭载芯片", "question": "Mate 80 Pro 相比 Mate 70 Pro，芯片升级了什么？", "answer": "从麒麟9020 升级为麒麟9030"}
]
```

## 质量自检清单

- [ ] 新旧方向明确（哪代是新的）？
- [ ] 答案含新旧两个值？
- [ ] 只对比了值不同的属性？
