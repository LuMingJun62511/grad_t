# Prompt: 2-3 同代横向对比

## 题型定义

信息结构：**题目指向同代的两个实体 S1 与 S2，题点是同一 R 下的值差异，答案是差异描述**。
用途：台阶二评测。两个实体的属性在台阶一单独训练过，对比问法只在评测出现。

前置条件：S1、S2 同属一个代/系列，同一属性 R 下两者值不同。

## 输入格式 (JSON)

```json
{
  "pair": [
    {"name": "Mate 80", "attributes": [{"relation": "搭载芯片", "value": "麒麟9020"}]},
    {"name": "Mate 80 Pro", "attributes": [{"relation": "搭载芯片", "value": "麒麟9030"}]}
  ],
  "tree_path": "华为 > 手机 > Mate 系 > Mate 80 系列"
}
```

## 输出示例

```json
[
  {"relation": "搭载芯片", "question": "Mate 80 和 Mate 80 Pro 的芯片有什么区别？", "answer": "Mate 80 是麒麟9020，Mate 80 Pro 是麒麟9030"}
]
```

## 质量自检清单

- [ ] 两侧值都来自输入？
- [ ] 只对比了值不同的属性？
- [ ] 答案只陈述差异、无优劣评价？
